Set up the admin password (one time)

This needs a GitHub token once. The token is encrypted with the password you choose and stored on the site; after that, editors only need the password.

  1. Open GitHub → New fine-grained token (as an account that can write to the repository). Choose an expiry (e.g. 1 year).
  2. Repository access: Only select repositories → vinayarya29/tensorelab.
  3. Permissions: Contents → Read and write; Actions → Read and write.
  4. Generate, copy and paste it below, then choose a password.
